# build-for-a-friend

Entry for the [Hacktoberfest Weekend Challenge: Build for a Friend](https://dev.to/challenges/hacktoberfest-weekend-2026-10-01) (DEV, Hacktoberfest 2026, week 1).

## Prompt

**Build something with open-source AI at its core** that solves a real problem for a friend or loved one.

- Core must be open tech: open-weight models, open-source agent frameworks, local inference, etc.
- Show why open matters for the use case (privacy, cost, customization, offline).

## Deadline

| | Time |
|---|---|

## Submission

Publish a DEV post using the challenge template, tagged `devchallenge`, `weekendchallenge`, `hf26challenge`.

Template sections:
- What I built and the problem it solves
- Demo / deployed link
- Code (embed GitHub repo)
- How I built it (open-source AI tools used)
- Why open innovation matters
- DevRelay agent session (optional, judged favorably)
- Prize categories entered

Teams: one member posts and credits teammates by username.

## Judging

1. Writing quality (weighted most)
2. Relevance to prompt and theme
3. Creativity
4. Technical execution
5. Use of partner tech (optional)
